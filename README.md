## Our approach

From the dataset used in the article, we chose our random variable to be the number of different OTUs observed in each sample. OTU richness is used here as a measure of plankton diversity.

We calculated the number of OTUs present in each sample and plotted these values in a histogram to examine their distribution. An OTU was considered present if its abundance was greater than zero.

We first considered using a Poisson distribution because our variable consists of count data. However, the variance in our observed data was much larger than the mean, indicating overdispersion. The samples were also collected from different ocean environments, which may contribute to the large variation between samples.

Because a negative binomial distribution can account for greater variation than a Poisson distribution, we chose it as our generative model.

Using the mean and variance of the observed data, we estimated the parameters \(n\) and \(p\) of the negative binomial distribution.

The model was then evaluated using non-parametrical bootstrapping to observe the paramater *p*'s precision and stability. Non-parametrical boostrapping was used because it relies on resampling of data as opposed to data being newly generated. This allows us to be more flexible in our assumptions about the negative-binomial distribution.

## Generative model

Our model is:

$$
X \sim \text{NegativeBinomial}(n,p)
$$

where \(X\) represents the number of different OTUs observed in one sample, with the unit **OTUs per sample**.

The model has two parameters:

- **n** – a shape/dispersion parameter with no physical unit. A larger \(n\) gives less relative variation, while a smaller \(n\) allows more variation between samples.

- **p** – a probability parameter between 0 and 1 with no physical unit. For a fixed value of \(n\), a lower \(p\) gives a higher expected number of OTUs and a larger variance.

The parameters are estimated from the observed mean and variance:

```python
n = mean**2 / (variance - mean)
p = n / (n + mean)
```

One observation from the fitted model can be simulated using:

```python
simulated_richness = np.random.negative_binomial(n, p)
```

This represents one possible OTU richness value for a sample generated by our model.
## Model evaluation

In order to evaluate the model that was chosen in its accuracy and validility bootstrapping was used, more specifically non-parametric bootstrapping. This allows us to be more lenient in our data collection and appraisal of probability distribution. 
We are evaluating the variable *p* using this model:  

```math
\left\{ r_{11}^{*}, r_{12}^{*}, \ldots, r_{1T}^{*} \right\}
= \text{1st bootstrap sample}

\vdots

\left\{ r_{B1}^{*}, r_{B2}^{*}, \ldots, r_{BT}^{*} \right\}
= \text{Bth bootstrap sample}
```


Each bootstrap sample contains the same number of observations as the original sample.

Methodically the method is very similar to Monte Carlo of using repeated random simulations to estimate a probability; but the random data is created by resampling with replacement from the original data as opposed to a computer random number generator.

The random data is generated by the following code:
```python
n_bootstrap = 1000
for i in range(n_bootstrap):
  bootstrap_sample = np.random.choice(values,size=len(values),replace = True)
```
To determine the error and uncertainty for variable *p*, a standardized error and confidence intervals were used:
```python
se_p = np.std(bootstrap_p, ddof=1) #Standardized error
ci_p = np.percentile(bootstrap_p,[2.5, 97.5]) #Confidence interval
```
